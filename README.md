# spotify_tracks_analysis
Разведочный анализ данных (EDA) музыкального датасета Spotify. Выполнена комплексная предобработка данных (очистка от пропусков и дубликатов), проведен анализ популярности исполнителей и жанровых тенденций, осуществлена визуализация ключевых закономерностей и сформированы аналитические выводы.
